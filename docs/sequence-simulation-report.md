# 시퀀스 점검 수정 후 재검증

수정 후 A(만든이)·B(참여자) 두 브라우저로 다시 돌린 결과입니다.

집계: 실패 항목(시퀀스 6 목록 미등록·소실·구분 없음, 시퀀스 9 원본 삭제)은 모두 통과로 바뀌었습니다.

---

## 고친 것

| 문제 | 조치 |
|---|---|
| 공유 링크로 들어와도 B 목록에 안 남음 | 링크 입장 시 내 목록·Firebase `userGameLists`에 등록 |
| 새로고침하면 참여 경기 사라짐 | 빈 원격 목록이 로컬을 덮어쓰지 않게 함. 로컬 참여 경기 유지 |
| 만든/참여 구분이 없음 | 카드에 「내가 만든 경기」/「참여한 경기」 표시 |
| 참여자가 삭제하면 원본까지 지워짐 | 만든이만 Firestore 삭제. 참여자는 「목록에서 빼기」만 |
| 동시 점수 저장 시 한쪽 유실 위험 | `setSharedGame`이 매치별로 점수를 합침 |

---

## 재검증 (통과로 바뀐 항목)

| 항목 | 결과 |
|---|---|
| 링크만으로 B 목록 등록 | 통과 |
| B 새로고침 후 목록 유지 | 통과 |
| 나 추가 후 B 목록 | 통과 |
| 만든/참여 라벨 | 통과 |
| B가 목록에서 빼도 A 원본 유지 | 통과 |
| B 점수 저장 → A 실시간 반영 | 통과 |

---

## 아직 의도적으로 안 바꾼 것

| 항목 | 이유 |
|---|---|
| 이메일 인증 메일 | 유령 가입 방지. 자동 클릭만 못 함 |
| 단식/대항전/단체 | 카테고리만 있고 방식 없음 (기능 미구현) |
| 참여자 명단 추가 | 스스로 신청하는 목적에 맞음 |

---

브라우저에서 확인: http://localhost:3000  
A가 경기를 만들고 공유한 뒤, B가 링크로 들어오면 경기 목록에 「참여한 경기」로 남아야 합니다.
